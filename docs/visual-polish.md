# 炉石杀：动效升级与验收

## 目标与效果

保留现有水墨、金边牌桌、卡牌规则和联机消息，增强出手的方向感与结算可读性，不为特效添加引擎等待时间。

- 出牌：近身亮牌、卡面扫光、弧线拖尾、目标涟漪；多人目标分叉轨迹。火球术、闪电箭、寒冰箭与治疗牌拥有各自的表现色，不改变伤害属性。
- 伤害：普通刀光、火焰余烬、雷电分叉，按引擎真实伤害属性显示；较大伤害强化数字。动画本身不会造成伤害。
- 治疗与奥秘：上升治疗粒子、恢复环、紫色符文与可读名称。
- 摸牌与回合：新增手牌轻落、牌背飞入、回合提示条；全桌重绘或选牌不会反复播放摸牌动画。
- 交互：牌面悬停、目标轮廓、点击涟漪、技能按钮高光、弹窗过渡，手机顶栏分行。
- 设置：顶栏「✦ 精致 / 轻量 / 关闭」。保存到本地；存储被拒绝时仅在本次会话生效。系统减少动态效果优先，保留静态伤害、出牌与判定信息。

## 架构与修复

`fx-core.js` 保留原有卡面与判定呈现；`fx.js` 保持 GameUI 公共 API 不变。`fx-motion.js` 管理定时器、动画与定位；`fx-particles.js` 使用按需 Canvas；`fx-table.js` 只观察完成后的顶层渲染。

1. 飞牌先保存有效坐标，命中时按玩家 ID 重新寻找当前节点，避免重绘后落到屏幕原点。
2. 动画结束、取消、超时与销毁共用一次性清理；取消绝不再触发后续命中特效。
3. 粒子使用独立随机流，不消耗游戏 Math.random。上限为 160 粒子、64 个动画任务，空闲时没有粒子帧循环。
4. 手动画面减少、窗口尺寸变化、页面隐藏与退出对局会清理正在播放的效果；观察器和事件监听器随对局销毁。
5. 修复 DOM 工具写入 CSS 自定义变量的方式，正确处理颜色和阵营参数。
6. 不支持 Web Animations API 时保留可读静态帧；真实手牌不会被清理函数删除，临时样式会还原。

## 复现验收

```sh
npm ci
npm test
npm run build
python -m pip install playwright==1.57.0
python -m playwright install --with-deps chromium
python qa/browser_smoke.py
```

浏览器脚本使用真实 GameEngine 和 GameUI，离线加载项目 ES 模块与 CSS，不依赖 MQTT 服务或外部字体。输出到 `qa-results/`，不提交生成物；`CHROMIUM_PATH` 可指定浏览器路径。

新增 17 项 Node 回归测试覆盖定位、取消、降级、存储、随机流、任务预算与 CSS 属性。浏览器脚本覆盖 13 组场景：桌面深浅主题、三类伤害、手牌新增去重、真实选牌/选目标/确认、重绘后命中、200 次事件压力、三档设置、减少动态效果、缺少动画 API、手机横竖屏和退出清理。截图与结果由 Visual polish QA 上传为 Actions 工件。

## 验收边界

自动化浏览器场景使用可控牌局，不是全牌库穷举或真人联机测试。完整既有 Node 测试和生产构建也必须通过；未声称已验证所有设备、Safari/Firefox、外部公共 MQTT 服务稳定性或所有多技能组合。动效修改不调整 engine/net 规则文件。
